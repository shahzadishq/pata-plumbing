# Pata Plumbing — one-page site

Single-file site (`index.html`) for Pata Plumbing, Jessie Pata, Lara VIC.

- Content from the Google Business Profile, Facebook and Instagram (phone, email, hours, services, reviews).
- Job photos are loaded from the Google Business Profile (lh3.googleusercontent.com). Before launch, download them into `assets/` and swap the URLs so the site doesn't depend on Google's links.
- Quote form opens the visitor's email app addressed to pataplumbing@gmail.com (no backend needed). Swap in Formspree or similar if you want submissions without email.
- Hosting: enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
